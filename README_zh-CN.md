在[下载页面](https://github.com/anefzaoui/misterdownloadmanager/releases/latest)上选择一个：

| 文件 | 何时选择它 |
| --- | --- |
| **`...-setup.exe`** | **不确定？就选这个。**它会安装 MDM、将其连接到你的浏览器，并询问你使用的语言。 |
| `...-portable.zip` | 你想把 MDM 放在 U 盘上或免安装使用：解压后运行即可。所有内容都保留在其文件夹中。 |
| `...-x64.zip` | 你想要不带安装程序的纯程序文件。 |
| `...-setup-arm64.exe`、`...-portable-arm64.zip`、`...-arm64.zip` | 同样的三个文件，适用于 **Windows on ARM**（骁龙及其他 ARM PC）。 |
| `...-setup-x86.exe`、`...-portable-x86.zip`、`...-x86.zip` | 同样的三个文件，适用于 **32 位 Windows 10**。在该平台上，请在 **Helpers** 中选择你自己的 ffmpeg 以获得最佳视频画质：因为没有为它构建、可供 MDM 检查的 ffmpeg。 |
| `...-extension-chromium.zip` | 你想手动添加浏览器扩展（Chrome、Edge、Brave、Opera、Vivaldi）。从商店安装更简单：[添加到 Chrome](https://chromewebstore.google.com/detail/mister-download-manager/ejoleppdfgjdndddcjoehopknmlglojp)、[添加到 Firefox](https://addons.mozilla.org/firefox/addon/mister-download-manager/)。 |

ARM64 和 32 位文件随 0.5.2 之后的每个版本一同发布；**检查更新（Check for updates）**会让每个副本始终使用与其处理器对应的文件。

> [!NOTE]
> Windows 在第一次运行时可能会显示 *“Windows 已保护你的电脑”*，因为这个早期版本尚未进行代码签名。点击**更多信息（More info）**，然后点击**仍要运行（Run anyway）**。

或者使用 [WinGet](https://learn.microsoft.com/windows/package-manager/winget/)（Windows 的包管理器）：在终端中，第一行安装 MDM，第二行更新它。

```
winget install AhmedNefzaoui.MisterDownloadManager
winget upgrade AhmedNefzaoui.MisterDownloadManager
```

### 在 Linux 上

MDM 也可以在 Linux 上运行，已在 Ubuntu 24.04、Debian 12 和 Fedora 上测试，桌面环境包括 GNOME、KDE Plasma、Xfce 和 Cinnamon，涵盖 X11 和 Wayland 会话：托盘、深色模式、浏览器集成（包括 Ubuntu 的 Snap 版 Firefox）以及软件包的安装。尚未实现：屏幕阅读器（Orca）无法读取其窗口，Flatpak 版浏览器无法与它通信（[更多](docs/getting-started.md#on-linux)）。在 0.2.4 及之前版本中，文件名以 `-experimental` 结尾。

| 文件 | 适用于 |
| --- | --- |
| `...-linux-x86_64.deb` | Ubuntu、Debian、Mint、Pop!_OS：`sudo apt install ./<file>.deb`。 |
| `...-linux-x86_64.rpm` | Fedora、openSUSE、RHEL：`sudo dnf install ./<file>.rpm`。 |
| `...-linux-x86_64.AppImage` | 任意 Linux。赋予可执行权限后运行。 |
| `...-linux-x86_64.tar.gz` | 纯程序文件，适用于任意发行版。 |
| `...-linux-arm64.*` | 同样的四个文件，适用于 64 位 ARM 计算机，自 0.5.2 之后的版本起提供（在 GitHub 的 ARM 机器上构建和测试）。 |

### 用 Mac？来做第一个尝试的人

**macOS**（Apple Silicon 和 Intel）的新构建也在同一个下载页面上，标记为 `-experimental`：我们自己还没有在 Mac 上试过它们。欢迎试一试并[告诉我们使用情况](https://github.com/anefzaoui/misterdownloadmanager/issues/new/choose)；你将帮助它们变得和 Windows 与 Linux 版本一样可靠。

| File | For |
| --- | --- |
| `...-macos-arm64-experimental.dmg` | 搭载 Apple Silicon（M1 或更高版本）的 Mac。打开它并将 MDM 拖到“应用程序”中。第一次运行时，右键点击该应用并选择**打开（Open）**。 |
| `...-macos-x86_64-experimental.dmg` | 搭载 Intel 处理器的 Mac，方法相同。 |

## 🌍 使用你的语言

Windows 11 提供的每一种语言，**共 86 种**。MDM 会在首次启动时询问，你也可以随时在 **View → Language** 中更改。阿拉伯语、希伯来语、波斯语、乌尔都语和维吾尔语会获得完全镜像的从右到左窗口。

## 功能

- **为每个下载加速**：同时获取文件的不同部分，并持续重新平衡，直到最后一个字节。
- **断点续传**：在崩溃、重启或连接中断后恢复下载，无需从头开始。
- **捕获来自 Firefox、Chrome、Edge、Brave、Opera、Vivaldi 和 Helium 的下载**（扩展位于 Firefox Add-ons 和 Chrome 应用商店），并在 MDM 未运行时将下载交还给浏览器。
- **从网页下载视频**（按钮会出现在视频上方；支持播放列表、字幕、仅音频）、使用 gallery-dl 下载**图片画廊**，以及下载**种子和磁力链接**（顺序下载、RSS 订阅、分享限制）。
- **一次处理多个链接**：链接抓取器（Link grabber）将它们整理成包，并在下载完成后解压压缩包（zip、7z、rar）。它从链接站点接收 Click'n'Load，每个站点只询问一次。Debrid 账户（Real-Debrid、AllDebrid、Premiumize、TorBox、Mega-Debrid；实验性）通过你自己的账户下载文件托管链接。
- **夜间下载**：通过队列和计划任务实现，可唤醒计算机，并可按你的需要随后关机。
- **仅通过你的 VPN**（如果你愿意）：将每个下载都限定在一个网络适配器上，带终止开关（kill switch），并可选择加密 DNS。每个下载都会显示其服务器所在的国家/地区。
- **从手机或在服务器上使用**：从家庭网络中的手机控制 MDM，或在 NAS 上以无窗口方式运行它（Docker、Unraid）（[方法](docs/server.md)）。
- **也可从脚本中使用**：IDM 的命令行开关、一个命令行工具，以及供其他程序使用的本地 API（[方法](docs/command-line.md)）。
- **与你的 AI 助手协作**：MCP 服务器让 Claude、Cursor 或 VS Code 可以列出、添加、暂停和删除你的下载（[设置方法](docs/ai-assistants.md)）。
- **为你留出速度**：限制单个下载或全部下载的速度，且仅在你使用计算机时限制。
- **日间与深色模式，以及主题**：Classic、Native、High contrast、Metro、Adwaita、Breeze、Luna、Aero 和 Aqua，或在文本文件中自定义你自己的主题（[方法](docs/themes.md)）。通过 **View → Interface size** 将一切放大，最高可达 200%。86 种语言，并提供适用于 U 盘的便携版。
- **支持键盘和屏幕阅读器**（Narrator、NVDA）：每个窗口、对话框和菜单（[按键](docs/keyboard-shortcuts.md)）。
- **无广告、无试用期、无需账户**。免费且开源。

## 基准测试详情

两个程序从同一个本地测试服务器（[labserver](crates/labserver)）下载相同的文件，并带有每个场景所指明的网络故障条件：每个场景运行七次，两个程序都使用各自的默认设置。MDM 在**全部七个场景**中都先完成；每个差异都具有统计显著性（Mann-Whitney p < 0.001），且 MDM 在每个场景中使用的 CPU 都更少。

## 不是逆向工程项目

MDM 是一个独立的、洁净室（clean-room）实现的程序。它是对一种熟悉的工作方式的重新实现，而不是对任何人软件的复制。

- **没有他人的代码或素材。**它不包含来自 Internet Download Manager 的任何代码、二进制文件、美术作品、图标、声音或文本，也不包含来自任何其他下载管理器的代码。应用图标是使用 ChatGPT（OpenAI 的图像生成）为 MDM 制作的；其他图标来自开放许可的图标集（[ATTRIBUTION.md](ATTRIBUTION.md)）。
- **没有拆解任何东西。**从未对任何 IDM 文件进行反汇编、反编译、调试、打补丁，或在其用户界面以下进行检查，其许可、试用和注册机制也从未被触碰或绕过。
- **像用户一样学习。**MDM 的功能是从 IDM 的公开文档和帮助页面、其公开截图中学习的，并通过将一份已获许可的副本作为黑盒使用来学习：从我们自己的测试服务器（[labserver](crates/labserver)）下载测试文件，并观察到达网络和屏幕上的内容。
- **建立在公开标准之上。**下载引擎遵循 HTTP 规范（RFC 9110、RFC 9112），并被独立设计、测试和测量。它的速度来自它自己的设计，基准测试证明了这一点。
- **无隶属关系。**MDM 与 Tonec Inc. 没有隶属、背书或关联关系。“Internet Download Manager”和“IDM”是其所有者的商标，在此仅用于描述人们已经熟悉的布局，并对两个程序进行比较。

## 面向开发者

<details>
<summary><b>从源码构建</b></summary>

需要 Rust stable 1.98 或更高版本（在 Windows 上使用 MSVC 工具链），并且为了引擎的类浏览器连接（BoringSSL，从源码构建）：需要 CMake、LLVM 的 libclang，并且在 Windows 上需要 NASM（`winget install Kitware.CMake LLVM.LLVM NASM.NASM`；在 Linux 上为 `cmake` 和 `libclang-dev`；在 macOS 上为 Xcode 命令行工具和 `cmake`）。`cargo build -p mdm-app --no-default-features` 可以在不带该连接的情况下构建应用（拒绝 MDM 自有连接的站点届时仍会被拒绝）。

```
cargo build --release
cargo test
```

这会在 `target\release\` 中生成 `misterdownloadmanager.exe`（应用）、`misterdownloadmanager-cli.exe`（无界面命令行）、`misterdownloadmanager-mcp.exe`（供 AI 助手使用的 MCP 服务器）和 `misterdownloadmanager-nmhost.exe`（浏览器宿主）。`tools\installer\build.ps1` 将安装程序和两个 zip 文件构建到 `target\dist\`（需要 [Inno Setup 6.3](https://jrsoftware.org/isinfo.php) 或更高版本），适用于 x64；使用 `-Arch arm64` 或 `-Arch x86` 可分别构建 Windows on ARM 或 32 位 Windows 版本（需先执行 `rustup target add aarch64-pc-windows-msvc` 或 `i686-pc-windows-msvc`）。`tools/installer/build-linux.sh` 为本机处理器（x86-64 或 ARM64）构建 Linux 文件。一个 `vX.Y.Z` 标签会在 GitHub Actions 上完成全部这些构建并发布版本。

## 状态与参与贡献

MDM 还很年轻：引擎、主窗口和浏览器集成在 Windows 和 Linux 上已经可靠，而某些角落目前仍只是“暂时够用”。

- **翻译由机器生成。**[`i18n/`](i18n) 中标记为 `#, machine` 的行正等待母语者修订；修正一行就是一个一行的拉取请求（pull request）（[方法](docs/languages.md)）。马来语的菜单、工具栏和下载列表列已由母语者审阅。
- 尚未完成：代码签名。macOS 构建未经测试；在 Linux 上，屏幕阅读器（Orca）和 Flatpak 浏览器尚未受支持。

欢迎在 [Issues](https://github.com/anefzaoui/misterdownloadmanager/issues/new/choose) 中报告 bug：应用内的 **Help → Report a problem** 会填入你的版本和系统信息。欢迎在 [Discussions](https://github.com/anefzaoui/misterdownloadmanager/discussions/categories/ideas) 中提出想法。拉取请求（pull request）按相同许可证接受：请从 [CONTRIBUTING.md](CONTRIBUTING.md) 开始。
